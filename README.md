# Asteria for Android

Asteria 是原生 Android 聊天客户端，采用白蓝和黑蓝主题。安装 `build/Asteria.apk`（Android 8.0 或以上），从左侧栏进入「设置 → API 设置」，填入开放平台 API Key 后点「测试并保存」。统一设置页也可切换外观、进入对话管理或查看版本。默认接口为 `https://api.deepseek.com`。

「模型提供商」有 DeepSeek 和 OpenAI 两个预设，分别自动填入 `https://api.deepseek.com` 和 `https://api.openai.com/v1`。两个预设都可编辑 API 接口地址，例如改成 `https://example.com/v1`，并分别记住已保存的地址和模型。模型列表通过当前接口的 `GET /models` 自动读取，也可手动填写模型 ID。支持 HTTPS 和显式填写的 HTTP 地址，无需鉴权的兼容服务可以留空密钥。OpenAI 和自定义接口使用 Chat Completions，支持文本多轮对话和流式回复。DeepSeek 官方地址支持附件、搜索和语音功能。应用按接口地址分别加密保存凭据，会话也绑定到各自的接口。

- 支持流式对话、深度思考、带来源的联网搜索、Flash 网页链接阅读、Markdown、复制和分享。官方通道会随消息提交设备日期，搜索结果和正文引用可打开网页来源面板。
- 支持图片及文档上传。联网搜索和含附件的对话使用 Flash。长按空输入框或切换到语音模式可录音，松手后转写到草稿，上滑可取消。官方模式使用 DeepSeek ASR，兼容模式使用手机安装的语音识别服务。朗读使用系统文字转语音。
- 对话侧栏可通过顶部菜单打开，也可从屏幕左侧滑出。会话按日期分组，长按会话可重命名、置顶、取消置顶、多选和删除。消息工具栏支持复制、编辑、朗读、分享、重新生成和续写。
- 点按自己的消息气泡即可在底部编辑，长按可复制消息。取消会还原普通输入区的草稿及待发送附件，重新发送会从被编辑的消息处生成新回复。回复工具栏仅出现在当前对话的最后一条回复下。
- Markdown 代码块带语言标签、高亮和独立复制按钮，过宽的代码和表格可横向滚动。向上翻阅对话时，可用输入框上方的箭头回到最新消息。
- 「设置 → 字体大小」可以跟随系统，或预览并选择聊天消息、代码块和输入框的字号。
- 「设置 → 自动压缩上下文」默认开启。长对话会在本机提取较早轮次的文字片段，发送时保留最近轮次。接口报告超限时可自动减少更多历史并重试。本地记录保留全文，较早附件可能从发给模型的上下文中省略。
- 通过已有对话顶部的齿轮，可为当前对话配置回复语气、自定义指令、最大输出 Token 和推理强度。DeepSeek 官方模式提供 Low、High 和 Max，随「深度思考」生效。生成时自动展开接口返回的思考过程，回复结束后收起，可点标题再次展开。关闭深度思考时默认发送温度 1.0，单对话设置可以覆盖。DeepSeek 的默认系统提示词包含设备日期，可通过自定义指令替换。OpenAI 兼容模式另外提供温度、Top-P、惩罚参数、随机种子、回复详略、JSON 对象、停止序列和上游扩展参数。
- API 设置里的「自定义提供商」支持自填名称和兼容接口地址。「密钥管理」可为同一接口保存多把密钥，并按轮询或随机方式用于普通对话。密钥列表只显示首尾片段，含附件的对话沿用附件密钥。
- 「设置 → 连接与数据 → 记录请求日志」默认关闭。开启后，对话顶部可查看请求正文、响应状态和流式数据。日志中的 API Key 会脱敏，仅在本次运行中保留，关闭开关时清除。
- 「设置 → SOCKS5 代理」支持按模型提供商配置代理地址及可选的用户名、密码认证。凭据加密保存。
- API Key 由 Android Keystore 加密，聊天记录存在应用私有目录。启用搜索、上传附件或使用语音时，相应内容会发给 DeepSeek 开放平台。附件上传后存于开放平台的文件列表，删除本地会话不会删除平台文件。

## 从源码构建

安装包可在 [GitHub Releases](https://github.com/Jiaozi06/Asteria/releases) 下载。应用打开时会检查更新，也可在「设置 → 关于」手动检查。发现新版时会展示更新说明。选择下载后直接打开 APK 链接，系统地区为中国大陆时使用 HTTPS 镜像。

在 Windows PowerShell 使用 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。

```powershell
.\build.ps1 -SdkRoot 'C:\Android\Sdk' -JavaHome 'C:\Java\jdk-17'
```

脚本下载并校验 CommonMark Java 0.32.0 及其 Markdown 扩展，使用 Android 原生控件渲染。依赖许可证随 APK 附带。脚本在本机生成并复用测试签名，APK 位于 `build/Asteria.apk`。启动器采用深蓝底、浅蓝星芒的自适应图标。
